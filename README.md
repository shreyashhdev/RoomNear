🏠 RoomNear

RoomNear is a web application built using HTML, CSS, and JavaScript that helps students find broker-free room and hostel accommodation near their college. Users can browse available rooms, filter listings by category, search by location, and list their own room for rent — all without dealing with brokers or extra fees.

> **Note:** This project is a work in progress and is being actively developed as a learning project in frontend web development.

-------------------------------------------------------------------
✨ Features
- 🔍 Search rooms near your college with a live search bar
- 🧭 Filter listings (e.g. All, Boys, Girls) with a single click
- ➕ List your own room for rent through a simple form
- 🏡 Clean, card-based home page for browsing available rooms
- 📱 Simple, responsive interface built for quick navigation
- ⚡ Lightweight — no frameworks, pure HTML/CSS/JS
-------------------------------------------------------------------
## 🛠️ Built With
- **HTML5** — structure and page layout
- **CSS3** — styling and responsive design
- **JavaScript** — page navigation, filtering, and search logic
------------------------------------------------------------------
## 🚀 Getting Started

Clone the repository and open `index.html` in your browser — no build step required.
```bash
git clone https://github.com/shreyashhdev/RoomNear.git
cd RoomNear
```
Then just open `index.html` in your browser of choice.
